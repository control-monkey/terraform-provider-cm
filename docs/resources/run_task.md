# cm_run_task (Resource)

Creates, updates and destroys run tasks. For more information: [ControlMonkey Documentation](https://docs.controlmonkey.io/main-concepts/stack/run-tasks)

## Example Usage
```terraform
resource "cm_run_task" "example" {
  name       = "My Run Task"
  url        = "https://my-run-task-endpoint.example.com/callback"
  is_enabled = true
  hmac_key   = "my-secret-hmac-key"
}
```

### Write-only HMAC key

`hmac_key` is stored in the Terraform state in plain text, because the ControlMonkey API never
returns it and `Sensitive` only masks CLI output. On Terraform / OpenTofu 1.11 and later, prefer
`hmac_key_wo` - a write-only argument that is never persisted to state or plan files.

Rotating the key requires incrementing `hmac_key_wo_version`. Changing `hmac_key_wo` on its own
produces no plan, because a write-only value is not stored and therefore cannot be compared.

```terraform
variable "run_task_hmac_key" {
  type      = string
  sensitive = true
}

resource "cm_run_task" "example" {
  name       = "My Run Task"
  url        = "https://my-run-task-endpoint.example.com/callback"
  is_enabled = true

  hmac_key_wo         = var.run_task_hmac_key
  hmac_key_wo_version = 1
}
```

## Schema

### Required

- `is_enabled` (Boolean) Whether the run task is enabled.
- `name` (String) The name of the run task.
- `url` (String) The URL of the run task endpoint.

### Optional

- `hmac_key` (String, Sensitive) The HMAC key for the run task. The API never returns this field, so it is stored in Terraform state in plain text. Prefer `hmac_key_wo`, which is never written to state.
- `hmac_key_wo` (String, Sensitive) The HMAC key for the run task, as a write-only argument. Unlike `hmac_key` the value is never persisted to Terraform state or plan files. Available on Terraform / OpenTofu 1.11 and later. Because a write-only value is not stored, the provider cannot detect a change to it - increment `hmac_key_wo_version` to send a new key.
- `hmac_key_wo_version` (Number) Version of `hmac_key_wo`. Increment this value to make the provider send the current `hmac_key_wo` to ControlMonkey. Changing `hmac_key_wo` on its own produces no change, because a write-only value is not stored and therefore cannot be compared.

### Read-Only

- `id` (String) The unique ID of the run task.
- `is_hmac_key_configured` (Boolean) Indicates whether an HMAC key has been configured for this run task.

## Import

`cm_run_task` can be imported using the ID of the Run Task, e.g.

```shell
terraform import cm_run_task.run_task rtsk-123
```
