# cm_run_task (Resource)

Creates, updates and destroys run tasks. For more information: [ControlMonkey Documentation](https://docs.controlmonkey.io/main-concepts/stack/run-tasks)

## Example Usage
```terraform
resource "cm_run_task" "example" {
  name       = "My Run Task"
  url        = "https://my-run-task-endpoint.example.com/callback"
  is_enabled = true
  hmac_key   = "my-secret-hmac-key"
}
```

## Schema

### Required

- `is_enabled` (Boolean) Whether the run task is enabled.
- `name` (String) The name of the run task.
- `url` (String) The URL of the run task endpoint.

### Optional

- `hmac_key` (String, Sensitive) The HMAC key for the run task. This is a write-only field and will not be returned in responses.

### Read-Only

- `id` (String) The unique ID of the run task.
- `is_hmac_key_configured` (Boolean) Indicates whether an HMAC key has been configured for this run task.

## Import

`cm_run_task` can be imported using the ID of the Run Task, e.g.

```shell
terraform import cm_run_task.run_task rtsk-123
```
