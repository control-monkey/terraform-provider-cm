# cm_organization_permissions (Resource)

Creates and destroys organization level permissions of a team. Each permission grants the team an organization role, which must be a `cm_custom_role` whose `type` is `organizationRole`. For more information: [ControlMonkey Documentation](https://docs.controlmonkey.io/administration/users-and-roles/custom-roles)

~> **Note** Organization permissions can only be managed for teams. The ControlMonkey API does not expose a way to read the organization permissions of a user or of a programmatic user, so those cannot be managed by Terraform.

## Example Usage
```terraform
resource "cm_custom_role" "platform_admin" {
  name = "platform admin"
  type = "organizationRole"

  permissions = [
    {
      names = ["org:stack:read", "org:stack:create"]
    }
  ]
}

resource "cm_organization_permissions" "platform_team" {
  team_id = cm_team.platform.id

  permissions = [
    {
      custom_role_id = cm_custom_role.platform_admin.id
    }
  ]
}
```
