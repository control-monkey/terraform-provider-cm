# cm_custom_flow_mappings (Resource)

Creates and destroys custom flow mappings. For more information: [ControlMonkey Documentation](https://docs.controlmonkey.io/main-concepts/runs/custom-flows)

## Example Usage

### Map a custom flow to a namespace and a stack
```terraform
resource "cm_custom_flow_mappings" "opa_validation_mappings" {
  custom_flow_id = cm_custom_flow.opa_validation.id

  targets = [
    {
      target_id   = cm_namespace.namespace.id
      target_type = "namespace"
    },
    {
      target_id   = cm_stack.stack.id
      target_type = "stack"
    },
  ]
}
```

### Map a custom flow to all namespaces in the organization
```terraform
# Map a custom flow to every namespace in the organization
resource "cm_custom_flow_mappings" "all_namespaces" {
  custom_flow_id = cm_custom_flow.opa_validation.id

  targets = [
    {
      target_id   = "ALL"
      target_type = "namespace"
    },
  ]
}
```
